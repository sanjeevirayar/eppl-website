PROJECT 03 ENGINEERED PROTOTYPE

Intelligent Data Center Infrastructure Monitor

Critical Infrastructure Data Center Monitoring Infrastructure Analytics

An intelligent infrastructure monitoring system developed to bring together power, cooling, environmental and equipment information so that the operating condition of critical data center infrastructure can be understood as one connected system.

← Back to Projects

THE CHALLENGE

Seeing infrastructure as one system.

Critical facilities depend on multiple infrastructure systems operating together. Power availability, battery condition, cooling performance, room temperature and equipment state all influence overall infrastructure reliability.

These systems are often monitored independently. A power alarm may be visible in one system while temperature behaviour, cooling demand or equipment loading is being observed somewhere else.

This project addresses that gap by collecting these different operating parameters into a common monitoring layer and examining how changes across power, cooling and environmental systems relate to each other.

THE CONCEPT

From isolated readings to infrastructure context.

The system operates as a monitoring layer above individual infrastructure equipment. It does not replace the existing protection or local control functions of UPS systems, cooling equipment or electrical panels.

Operating information from multiple infrastructure sources is collected and organized into a shared view of the facility.

Electrical demand, backup-power condition, cooling operation and environmental behaviour are then examined together so that abnormal conditions can be understood within the wider infrastructure state.

Monitoring Philosophy

The prototype combines power, cooling and environmental information into one monitoring layer so relationships between infrastructure systems can be observed over time. Monitoring remains independent from equipment protection and local control systems.

02

Infrastructure Condition Model

Equipment information is grouped into infrastructure operating states so that individual alarms can be interpreted within the wider facility condition.

STATE INFRASTRUCTURE CONDITION SYSTEM INTERPRETATION
S0 Normal Power, cooling and environmental parameters remain within expected operating patterns without significant active infrastructure events.
S1 Changing One or more infrastructure parameters are moving away from their normal behaviour while remaining within acceptable operating conditions.
S2 Degraded An equipment alarm, abnormal trend or reduced-redundancy condition is present and requires operational review.
S3 Critical Multiple related conditions or a significant infrastructure event require immediate investigation or operational response.

04

Monitoring & Reliability Philosophy

The monitoring platform improves visibility while remaining independent from the equipment-level protection required for critical infrastructure operation.

01

Read-Only Monitoring

Infrastructure interfaces are kept read-only where control capability is not required, reducing unintended interaction with critical equipment.

02

Local Protection Remains

UPS protection, breakers, cooling controllers and equipment-level safety systems remain independent from the monitoring platform.

03

Communication Failure Tolerance

Loss of communication with the monitoring platform does not interrupt normal operation of the monitored infrastructure equipment.

04

Data Quality Monitoring

Missing, stale and invalid measurements are identified so unavailable data is not interpreted as normal equipment condition.

05

Alarm Context

Correlation provides additional context for investigation while equipment-specific alarms remain visible individually.

06

Network Segmentation

Infrastructure monitoring communication is separated from unrelated network functions to maintain a controlled monitoring architecture.

DEVELOPMENT APPROACH

From equipment data to infrastructure insight.

The system was developed progressively, beginning with infrastructure mapping and equipment integration before moving into centralized data collection, visualization and correlation.

01

Infrastructure Mapping

Identified monitored equipment, measurement points, communication interfaces and operational relationships.

02

Equipment Integration

Integrated UPS, SMPS, cooling, metering and environmental devices through their available monitoring interfaces.

03

Data Acquisition

Normalized equipment measurements, timestamps, alarms and operating states into a common data structure.

04

Monitoring Interface

Developed infrastructure views, equipment dashboards, trend displays and event visualization.

05

Correlation Logic

Implemented rules for relating power, cooling, environmental and equipment-state changes.

06

Validation & Refinement

Tested monitoring behaviour using equipment state changes, communication interruptions and simulated infrastructure-event scenarios.
