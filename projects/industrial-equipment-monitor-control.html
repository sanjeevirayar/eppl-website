PROJECT 04 ENGINEERED PROTOTYPE

Industrial Equipment Behaviour & Production Monitor and Control

Industrial Automation Condition Monitoring Production Control

An industrial automation system developed to monitor machine condition, operating state and production activity while coordinating motor speed, equipment operation and operator alerts through PLC-based control.

← Back to Projects

THE CHALLENGE

Understanding what the machine is actually doing.

Industrial equipment may continue producing even while motor load, vibration, temperature or production behaviour gradually moves away from normal operating conditions.

Production count alone shows output, while condition sensors alone show equipment behaviour. When these signals are monitored separately, the relationship between machine condition and production performance can be difficult to understand.

This project combines machine-condition sensing, production detection and PLC control into one system, allowing equipment behaviour and production activity to be evaluated together.

THE CONCEPT

From machine signals to operational control.

The system combines conventional PLC automation with equipment-condition monitoring and production sensing.

Vibration, bearing temperature and rotational speed provide information about equipment behaviour, while the drive communicates motor operating information and the photoelectric sensor tracks production output.

The PLC processes these signals together and maintains the current machine state. When operating conditions move outside the configured production rules, the system can generate an operator warning, modify the drive command or stop the production sequence.

System Principle

The prototype combines equipment-condition sensing with production monitoring so machine behaviour can be evaluated alongside actual production activity. Operational control remains separate from certified machine-safety functions.

02

Machine Operating-State Model

Sensor and production information is interpreted according to the current machine state so that startup, normal production and abnormal conditions are handled differently.

STATE MACHINE CONDITION SYSTEM BEHAVIOUR
S0 Stopped Motor command is disabled, rotational feedback is absent and production counting is paused while condition values remain visible.
S1 Starting The VFD accelerates the machine to the requested operating speed while rotational feedback confirms movement.
S2 Production Machine condition, production count and throughput are continuously monitored while normal control commands remain active.
S3 Deviation A sustained abnormal equipment or production condition generates an operator warning and initiates the configured operational response.

04

Control & Safety Philosophy

Condition-based PLC control is used for operational management only. Machine safety remains independent from the normal automation program.

01

Independent Emergency Stop

The SIRIUS 3SK1 safety relay handles the emergency-stop circuit independently from standard PLC program execution.

02

Controlled Machine Stop

Condition-monitoring logic can command a normal controlled stop without treating that function as a substitute for emergency safety.

03

Speed Verification

The IFS252 provides independent rotation feedback so commanded VFD speed can be compared with actual machine movement.

04

Analog Signal Monitoring

Vibration and temperature transmitters use industrial analog signals that are monitored for valid operating ranges.

05

Operator Supervision

Machine state, alerts and control actions remain visible on the HMI so automated responses can be understood by the operator.

06

Protection Remains Separate

Motor protection, emergency stopping and other required machine-safety functions remain independent from condition-monitoring logic.

DEVELOPMENT APPROACH

From machine sensing to production control.

The prototype was developed progressively from equipment sensing and PLC integration through motor control, production tracking, HMI development and operating-state testing.

01

Machine Instrumentation

Installed vibration, temperature, rotational and production-detection sensors around the equipment test platform.

02

PLC Integration

Connected digital and analog sensor signals to the S7-1200 and configured scaling, filtering and equipment-state inputs.

03

Motor Control

Integrated the SINAMICS V20 with the PLC for run commands, variable-speed operation and drive-state communication.

04

Production Logic

Developed object counting, production-rate tracking and equipment-state sequencing using photoelectric detection.

05

HMI Development

Built operator screens for machine state, production count, sensor trends, VFD speed, warnings and manual controls.

06

Testing & Refinement

Tested startup, production counting, speed changes, abnormal sensor conditions, controlled stopping and safety-interface behaviour.
